# Velgrim — Crimson Blaze

Hero game yang dibuat dengan React, TypeScript, Vite, Tailwind CSS, dan Motion.

```bash
npm install
npm run dev
```

Buka alamat yang ditampilkan Vite. Untuk build produksi jalankan `npm run build`, lalu `npm run preview`. Tautan sosial dapat dikonfigurasi pada array `socials` di `src/main.tsx`; URL resmi dan trailer belum disediakan dalam brief.
